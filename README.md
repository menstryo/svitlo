# Світло — графік відключень для iOS 6

Застосунок для iOS 6 (Theos, MRC, armv7) + агрегатор графіків відключень світла по всій Україні.

## Як це працює

GitHub Actions кожні 10 хвилин запускає `scripts/build.mjs`: він збирає графіки з усіх джерел, зводить їх в один формат і публікує на GitHub Pages:

- `regions.json` — список регіонів
- `schedule/<id>.json` — графік по чергах

Застосунок читає ці файли. Ніякого власного сервера не потрібно.

## Застосунок

Встанови `Svitlo.ipa` через 3uTools (є і на сторінці Pages). При першому запуску вибери **Регіон** → **Чергу**.

Можливості: статус «є / немає світла» з відліком до наступної зміни, графік на сьогодні й завтра (48 півгодинних клітинок), список відключень, локальні сповіщення за 5–60 хв, офлайн-кеш.

### Збирання (WSL)
```bash
cd app && make package FINALPACKAGE=1
```

## Джерела
| Регіони | Звідки |
|---|---|
| Київ, Дніпро | API YASNO |
| Київська, Одеська, Дніпропетровська (ДТЕК) | github.com/Baskerville42/outage-data-ua (MIT) |
| Харківська, Львівська, Запорізька, Полтавська, Черкаська, Чернігівська, Житомирська, Хмельницька, Івано-Франківська, Рівненська, Тернопільська, Закарпатська | github.com/yaroslav2901/OE_OUTAGE_DATA |

Не покриті: Вінницька, Волинська, Кіровоградська, Миколаївська, Херсонська, Сумська, Чернівецька — їхні обленерго публікують графіки картинками чи постами, відкритих машиночитаних даних немає. Новий регіон = рядок у `REGIONS` у `worker/src/index.js` + конвертер у формат 48 символів.

## Формат
```json
{ "id":"kyiv", "name":"Київ", "updated":"...", "today":"2026-10-02", "tomorrow":"2026-10-03",
  "queues":[ {"id":"1.1", "today":"000000001111...(48)", "tomorrow":null} ] }
```
Кожен символ — 30 хв від 00:00 за Києвом: `0` світло є, `1` немає, `2` можливо. `null` — графік ще не опубліковано.
